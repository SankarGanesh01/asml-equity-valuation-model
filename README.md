# ASML Holding N.V. - Equity Valuation Model

## Overview

This project evaluates ASML Holding N.V. using an Excel-based financial model and an accompanying asset-pricing report dated **March 2026**.

The analysis combines discounted cash flow valuation, comparable-company multiples, and CAPM-based cost-of-equity estimation to assess the company's valuation under different assumptions.

## Valuation Methods

- **Discounted Cash Flow (DCF):** Free Cash Flow to the Firm (FCFF) discounted using the weighted average cost of capital (WACC).
- **Comparable-company valuation:** Relative valuation using market multiples.
- **CAPM:** Estimation of the cost of equity using systematic risk and the market risk premium.
- **Scenario and sensitivity analysis:** Examination of how valuation changes with assumptions such as WACC and terminal growth.

4. Examine the summary and scenario sensitivities.
5. Read the report alongside the workbook to understand the rationale and limitations of the valuation.

## Important Validation Note

Before relying on the valuation, reconcile the base-case DCF value with the sensitivity table and ensure the reported target price agrees with the workbook's formulas and assumptions. The report and model should use consistent figures.

## Limitations

- Valuation depends on forecasts, discount rates, terminal growth, peer selection, and market inputs.
- DCF and relative valuation produce estimates, not guaranteed future share prices.
- The model represents a historical academic analysis and should not be interpreted as a current investment recommendation.
- Conclusions depend on the accuracy and consistency of the underlying inputs and formulas.
