# Data Documentation

## Project

ASML Holding N.V. - Equity Valuation Model.

The model uses financial inputs and assumptions to estimate ASML's value using FCFF DCF, comparable-company valuation, and CAPM.

## Data Categories

The Excel workbook includes a dedicated inputs sheet and a historical financials sheet.

| Data category | Purpose |
|---|---|
| Historical financials | Provides the historical financial information used in the analysis. |
| Valuation assumptions | Supplies the assumptions required for the DCF model. |
| Market and risk inputs | Supports CAPM, cost-of-equity estimation, and discount-rate calculations. |
| Comparable-company inputs | Supports relative valuation using peer-company multiples. |
| Scenario assumptions | Allows valuation sensitivity to key modelling inputs. |

## Data Sources and Validation

Refer to the workbook and accompanying report for the specific input values and source references. Verify that each financial figure, market input, peer multiple, and valuation assumption is traceable to its original source.

The report is dated March 2026. This is the report date, not confirmation that every input was retrieved on that date.

## Reproducibility

The Excel workbook contains the calculations and assumptions used in the valuation. To review the analysis:

1. Inspect the inputs and historical financials sheets.
2. Trace the inputs into the DCF and comparable-company calculations.
3. Check the CAPM assumptions and discount-rate calculations.
4. Reconcile the summary valuation with the scenario and sensitivity outputs.

This repository does not provide a separate automated data-download pipeline.
